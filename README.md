# Liz Showroom - Sistema de Gestión para Boutique

## Descripción

**Liz Showroom** es un sistema de escritorio desarrollado como mi **proyecto final de la Tecnicatura Superior en Desarrollo de Software**. El objetivo principal fue crear una solución que permitiera administrar las operaciones diarias de una boutique, centralizando la gestión de productos, ventas y reportes.

Este proyecto representa el cierre de una etapa de formación y, al mismo tiempo, el comienzo de mi camino como desarrollador profesional.

## Funcionalidades

* Gestión de productos y categorías.
* Control de stock.
* Registro de ventas.
* Administración de clientes.
* Generación de reportes.
* Manejo de caja.
* Búsquedas y filtros de información.

## Tecnologías utilizadas

* **Lenguaje:** C#
* **Framework:** .NET Framework 4.7.2
* **Interfaz:** Windows Forms
* **Base de datos:** Microsoft Access (.accdb)
* **IDE:** Visual Studio

## Arquitectura y diseño

El proyecto fue desarrollado como una aplicación de escritorio de usuario único, priorizando la funcionalidad y la resolución de problemas reales por encima de una arquitectura compleja.

Debido a que fue uno de mis primeros proyectos de gran tamaño, existen muchas decisiones de diseño que hoy abordaría de una manera diferente. Algunas de ellas incluyen:

* Organización del código mejorable.
* Separación de responsabilidades limitada.
* Escaso uso de patrones de diseño.
* Poca automatización de pruebas.
* Algunas decisiones técnicas tomadas por desconocimiento o por las limitaciones de tiempo.

## Lo que aprendí

A pesar de sus limitaciones, este proyecto me permitió aprender y poner en práctica conceptos muy importantes:

* Diseño e implementación de bases de datos relacionales.
* Desarrollo de aplicaciones de escritorio con C# y WinForms.
* Manejo de conexiones y consultas a bases de datos.
* Resolución de problemas reales planteados por un cliente.
* Modelado de entidades y relaciones.
* Organización de un proyecto de software de principio a fin.
* Depuración y mantenimiento de código existente.
* Importancia de la planificación y de las buenas prácticas de desarrollo.

## Reflexión personal

Este proyecto no es perfecto y probablemente contenga muchos errores que hoy puedo identificar. Sin embargo, estoy orgulloso de él porque representa todo lo que aprendí durante mi formación.

Cada línea de código escrita aquí fue una oportunidad para equivocarme, investigar y mejorar. Gracias a este proyecto comprendí que desarrollar software no consiste únicamente en hacer que el programa funcione, sino también en escribir código mantenible, escalable y fácil de entender.

Espero que este repositorio sirva como una muestra de mi evolución como desarrollador y como un punto de referencia para futuros proyectos, en los cuales aplicaré mejores prácticas, arquitecturas más sólidas y nuevos conocimientos.
